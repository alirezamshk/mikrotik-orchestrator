# MikroTik Fleet Orchestrator

سیستم مدیریت و اتوماسیون متمرکز سرورهای میکروتیک (RouterOS 7.x).

## ویژگی‌ها:
- **کانفیگ خودکار روتر جدید (Bootstrap):** تنظیم سرویس‌های OpenVPN, IKEv2 (EAP-RADIUS), L2TP, فایروال، MSS Clamping و اسکریپت‌های مانیتورینگ.
- **افزودن ماژولار کشورها (Destination Provisioner):** ساخت خودکار اینترفیس GRE، جدول روتینگ، روت خروجی، روت بلک‌هول (Killswitch)، Pool، پروفایل PPP، پورت OpenVPN اختصاصی و منگل با استثنا کردن ایران ().
- **مدیریت چندسروره (Multi-Server Fleet):** اعمال تغییرات به صورت تکی یا همزمان روی تمام سرورها.
- **داشبورد تحت وب و REST API:** وب سرویس مدرن بر پایه FastAPI.
